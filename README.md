# Cool Stand Game

## About
Cool Stand Game is a Unity game project inspired by JoJo's Bizarre Adventure. Summon your Stand and use unique abilities to fight enemies.

## Features
- Stand summoning and combat
- Sword-based combat mechanics
- Custom animations and visual effects
- Unique abilities and gameplay mechanics

## Built With
- Unity
- C#
- Blender (3D modeling and animation)

## How to Play
1. Clone or download this repository.
2. Open the project using Unity Hub.
3. Open the main scene.
4. Press Play to start the game.

## Installation
Clone this repository:

```bash
git clone https://github.com/chrisxu2009/Cool-Stand-Game.git
```

Open the downloaded project in Unity Hub.
